
# Regional Carbon Metabolic Resilience under Sequential Shocks
序列式冲击下的区域碳代谢韧性

## Overview
This repository contains the data processing procedures, analytical
code, and supporting results for the study of regional carbon metabolic
resilience under sequential shocks in China.
本库包含中国区域碳代谢系统在连续冲击下韧性研究所需要的数据处理过程、分析代码及相关结果。

## Study Area
30 provincial-level administrative regions in China.

## Research Components
-逐日碳排放反事实基准线计算及可视化
-冲击识别
-基础碳代谢韧性指标计算
-适应轨迹划分
-冲击后状态延续计算

## Data Availability
Original data are obtained from their respective sources.
Data availability and redistribution are subject to the terms of
the original data providers.

## Code Structure
- code/: data processing and analytical scripts
- data/: documented, shareable datasets
- results/: supporting analytical outputs

## Requirements
Python3.7
